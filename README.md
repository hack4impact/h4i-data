# backend-test
This is a repository for testing Prisma orm, jest tests, and databases.

--- 

## 🛠 Techs

- **Express** — Javascript backend framework
- **PostgreSQL** — database
- **Prisma** - Object relational mapping
- **Jest** - Testing framework, CI

---

```bash
npm i
```
